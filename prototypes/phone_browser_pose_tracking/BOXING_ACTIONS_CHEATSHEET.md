# Boxing action labels

Use these exact labels in video sidecar files. Punch numbers follow this project's glossary mapping; numbers can vary between gyms.

| Label | Action |
| --- | --- |
| `1` | Jab |
| `2` | Rear straight |
| `3` | Lead hook |
| `4` | Rear hook |
| `5` | Lead uppercut |
| `6` | Rear uppercut |
| `1b` | Body jab |
| `2b` | Rear straight to the body |
| `3b` | Lead hook to the body |
| `4b` | Rear hook to the body |
| `5b` | Lead uppercut to the body |
| `6b` | Rear uppercut to the body |
| `lead_slip` | Slip toward the lead side |
| `rear_slip` | Slip toward the rear side |
| `lead_roll` | Roll toward the lead side |
| `rear_roll` | Roll toward the rear side |

Pivot labels are intentionally not included yet. The supported list lives in the shared `packages/boxing-detection` package so annotations, reports, and future consumers use the same vocabulary.
