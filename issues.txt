Issue	What your code currently does	Why it matters / suggested change
1. Evaluation can count the wrong punch as correct	In evaluate.ts, nearestPrediction() matches using arm and timestamp, without checking the action label.	An expected hook can match a detected jab and increase matchedActions; it can also increase matchedJabs. Fix this first so the report can be trusted. Track time-matched classification errors separately from correctly labeled events.
2. Motion depends on frame rate	extensionDelta and wrist movement are per-frame differences. Movement and idle conditions use frame counts.	The same punch can behave differently on a slower phone. Calculate motion using elapsed seconds, and replace frame-count conditions with durations.
3. Coordinate scales are mixed	ArmObserver.distance() combines normalized image x, y, and relative z directly. The worker sends result.landmarks, not worldLandmarks.	This isn’t a consistent Euclidean coordinate system: portrait aspect ratio affects the geometry. Use aspect-corrected 2D features and separately evaluated depth features, or validate world-coordinate features.
4. Tracking-loss reset misses a common case	pipeline.ts checks the gap between consecutive incoming frames, even when landmarks are null.	If null frames keep arriving regularly, tracking can be lost for seconds without a reset. The observer retains old wrist coordinates and can compare them with a newly acquired pose. Track time since the last valid observation per arm.
5. “Forward” means toward the camera	Forward motion is previousWrist.z - currentWrist.z.	This fits your intended front-facing setup, but a punch thrown sideways relative to the camera can fail. Explicitly constrain camera placement for V1; later consider a calibrated body-relative direction.
6. Retraction is labeled as recovery	An event becomes recovered when the arm’s extension ratio drops below 0.7.	A hand pulled down to the waist can satisfy this. Call it “retracted,” or require the wrist to return to a calibrated guard region before reporting guard recovery.
